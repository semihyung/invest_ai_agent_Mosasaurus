# Price Conventions (명세 v3.7.4 4.2·5.1·6.1절)

## 기준 분리

| 용도 | 사용 가격 |
| ----- | ----- |
| 모멘텀·120MA·수익률·백테스트 신호 | 직전 거래일까지 완료된 수정 종가 (`adjusted_close`) |
| 트레일링 스탑 고점 (`PeakPrice`) | 보유 시작 이후 **완료 수정 종가 최고치**와 최초 매수 체결가(수정 기준) 중 큰 값, 마감 스냅샷에서 하루 1회 갱신 |
| 주문·호가·체결·계좌 평가 | KIS 원주가 (raw price) |

진행 중인 당일 일봉은 주간 순위와 백테스트 신호에 포함하지 않습니다. `morning_prep` 에서 최근 200거래일 일봉을 일괄 Upsert 하여
소급 수정주가 변경을 감지합니다.

## 조정계수 방향

완료 거래일 `d` 의 조정계수는 `A(i, d) = adjusted_close / raw_close` 입니다. KIS 수정주가는 최신 거래일 기준으로 과거를 소급 조정하므로
정상 상태에서 **가장 최근 완료 거래일의 `A` 는 1.0**, 과거 일자는 `≤ 1.0` 입니다. 따라서 당일 실시간 원주가는 현재 수정 기준과 같은
척도(`adjusted_live_price = raw_live_price × 1.0`)이며, 이 등식은 아래 "기준 유효성 규칙"을 만족할 때만 씁니다 `[UNVERIFIED: KIS 소급 조정 방식]`.

## 기준 유효성 규칙 (이벤트 0건 = 계수 1.0 유효)

1. 당일 200거래일 Upsert 후 기존 저장 시계열 대비 모든 일자의 `A` 변화가 허용오차(`1e-6`) 이내(소급 조정 없음).
2. `corporate_actions` 에 `ex_date` 가 (마지막 완료 거래일, 오늘] 구간인 이벤트가 없음.
3. 최근 완료 거래일 `A = 1.0`.

하나라도 어긋나면 **그 종목만** `CORPORATE_ACTION_UNVERIFIED` 로 격리하고(시스템 전체 `SAFE_HALT` 로 올리지 않음)
`verified = 0` 후보 레코드(감지 `ex_date`, 암시 계수 `f` = 새 `A` / 기존 `A`)를 만듭니다.

## 기업행위 검증

- **자동 검증**: 운영자 승인 분배 일정(`universe_allowlist.yaml` 의 `distribution_schedule`)의 `ex_date` 와 일치하고 `f ∈ [0.95, 1.0)` 인 현금 분배.
- **운영자 확인**: 그 밖(분할·병합·일정 외 분배·범위 밖 계수)은 Telegram `/ca_confirm` 2단계 확인으로만 검증.
- 검증 시 같은 트랜잭션에서 `positions.peak_price_adj` 에 `f` 를 곱해 재기준화하고 격리를 해제합니다(`confirm_corporate_action`).
- 가격 차이만으로 종류·발생일·계수를 추정하거나 `verified = 1` 로 기록하지 않습니다.
- 격리 중인 보유 종목은 가격 기반 자동 매도와 신규 매수가 보류되고 매일 브리핑으로 알립니다.

## 호가 단위

주문 가격은 원주가 기준 KRX ETF 호가 단위로 산출합니다: 2,000원 미만 1원, 이상 5원 `[UNVERIFIED]`.
`down(p) = p − tick(p − 1)` 로 한 호가 아래를 구해 경계에서도 정확합니다.

## 데이터 품질

일간 수익률 ±30% 초과 미검증 이상치, 수정주가 불연속, 결측·0 이하 가격은 해당 종목 `PRICE_SERIES_INVALID` 입니다.
